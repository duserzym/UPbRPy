workflow for the LA-ICP-MS data visualization GUI

1) load the LAICPMS experiment data from Thermo iCAP
2) use the auto-baseline and peak detection algorithm to detect baseline and peaks in the data
3) go through the auto-selected baselines and peaks and manually adjust them if necessary, save the selections along the way
4) view the primary standard measurements which is supposed to be bracketing the unknown samples and look at the fractionation across the whole session
5) at the same time, view the aligned downhole fractionation data for the primary standard
6) once satisfied with the picks, hit UPbR! button and process the data which incluses:
    - intensity channels
