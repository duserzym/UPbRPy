# Application icon

`upbrpy_studio.svg` is the approved variant A master, generated by
`make_icon.py`. It shows three time-resolved laser-ablation signals, a blue
integration window and a blue zircon with a laser spot on a gridded paper panel.
The crystal is the Mineral Habit Matrix (MHM) Pupin S8 zircon, projected from
`zircon_S8.stl`.

The shared lab app family style uses a softly shaded white rounded tile with
transparent outer corners, a pale grey border, paper panels, fine facet edges
and soft shadows. The palette uses blue (`#4063d8`) for the zircon and integration
window, red (`#cb3c33`), green (`#389826`) and purple (`#9558b2`) for the signals,
and slate grey for the grid and axes.

Crystal model credit: [mineral-habit-matrix](https://github.com/duserzym/mineral-habit-matrix),
by Yiming Zhang, MIT licence. The tile, palette, projection helpers and shadow
definitions share the family style used by GrainAtlas.

## Rebuild

Obtain the zircon STLs from
[`models/stl/zircon`](https://github.com/duserzym/mineral-habit-matrix/tree/main/models/stl/zircon)
in mineral-habit-matrix. Keep the STL checkout outside this repository.
From the UPbRPy repository root, run:

```sh
python GUI/assets/icons/make_icon.py <stl_dir>
python regenerate_icons.py
```

The first command defaults to variant A and requires NumPy. Alternatively,
`python regenerate_icons.py --stl-dir <stl_dir>` runs both steps.

The exporter uses `rsvg-convert` (Homebrew, on PATH) to render each of the ten
PNG sizes directly from the SVG, preserving `feDropShadow` and `feGaussianBlur`.
If it is missing, the exporter prints a warning and uses QtSvg, which loses
these shadows. Pillow packs the directly rendered sizes into the ICO. The ICNS
uses those same renders, with native 16/32px RGB and alpha resources and PNGs
for the larger and Retina entries.

Output names remain `png/upbrpy_zircon_*.png`, `upbrpy_zircon.iconset/`,
`upbrpy_zircon.ico` and `upbrpy_zircon.icns` for packaging compatibility.
The running GUI loads the pre-rendered PNGs; the programmatic crystal renderer
remains a fallback. Large previews and source models stay outside this repository.

## Previous artwork

`upbrpy_isotope_geology.svg` is the superseded IGL/Sawtooth mark, kept for
reference. Its terrain provenance is preserved below.

Terrain is derived from the USGS 3DEP elevation service:
https://elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer

Region: Sawtooth Range, central Idaho. The exported 193 × 145 grid has UTM 11N
bounds 646276.6649423916, 4879108.101891494 to 670546.4407463553,
4897341.871277892. Rows 24–120 supply the 193 × 97 terrain mesh.
Elevation range: 1541.08–3256.81 metres. Vertical exaggeration: 3×.
The lavender colors are artistic hillshading, not a snow or vegetation map.
