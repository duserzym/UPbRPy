# Keyboard shortcuts

**Help > Keyboard Shortcuts** lists the active tab's current bindings. In the
table below Ctrl means Command on macOS, except Ctrl+Tab, which uses Control.
Single-letter shortcuts do not fire while typing in a text field. Selection
editing shortcuts apply in the import and selection steps.

| Action | Keys |
| --- | --- |
| Save project and pending window edits | Ctrl+S |
| Recalculate without saving | Ctrl+Shift+Return; Ctrl+Return on Selections |
| Run this step's primary action | Ctrl+Return |
| Previous / next workflow step | Ctrl+[ / Ctrl+] or Ctrl+Left / Ctrl+Right |
| Previous / next acquisition | Ctrl+Up / Ctrl+Down or comma / period |
| Activate baseline / plateau editing | B / P |
| Move window start one sweep earlier / later | Alt+Left / Alt+Right |
| Move window end one sweep earlier / later | Alt+Shift+Left / Alt+Shift+Right |
| Undo / redo selection edit | Ctrl+Z / Ctrl+Shift+Z |
| Re-pick current acquisition | R |
| Re-pick all acquisitions | Ctrl+Shift+R |
| Re-pick current sample | Ctrl+Alt+R |
| Re-pick all open tabs | Ctrl+Alt+Shift+R |
| Toggle current acquisition's calculation exclusion | Ctrl+E |
| Return to raw traces | T |
| New tab / close tab | Ctrl+T / Ctrl+W |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab |
| Select tab 1–8 / last tab | Ctrl+1 through Ctrl+8 / Ctrl+9 |
| New window | Ctrl+Shift+N |
| Show reduction notes and activity log | Ctrl+Shift+L |
| Submit reduction to database | Ctrl+Shift+D |
| Show shortcut sheet | Ctrl+/ |

In concordia plots: click selects, Shift-click extends, Command/Ctrl-click
toggles, H hides the selection, Shift+H shows all, E toggles calculation
exclusion, Escape clears selection and Command/Ctrl+A selects shown spots.
Double-click resets the plot. In the chooser, Space toggles visibility checks.

Use **Window > Move Tab to New Window** to move a reduction with its state.
Use **View > Reset Layout** to fit the layout to the current display. On a
small display, restore collapsed panels from View; auto-pick settings fold
behind their toggle. Every stage remains accessible through the native menus.
